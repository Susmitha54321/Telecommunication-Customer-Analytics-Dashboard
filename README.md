# 📊 Telecommunication Customer Analytics Dashboard (Power BI)

## 📖 Project Description

This project presents an interactive Telecommunication Customer Dashboard built using Power BI to analyze customer behavior, revenue distribution, and service usage patterns.

The dashboard provides insights into key metrics such as total revenue, monthly charges, customer tenure, and distribution across cities and offers. Users can explore the data dynamically using slicers like Internet Type and Customer ID to uncover trends and patterns effectively.

---

## 🛠️ Tech Stack

* Power BI (Data Visualization & Dashboard Creation)
* Power Query (M Language for Data Transformation)
* DAX (Data Analysis Expressions for calculations)
* Microsoft Excel (Data Source)
* GitHub (Version Control & Project Sharing)

---

## ✨ Features & Highlights

* Interactive KPI cards displaying:

  * Total Revenue
  * Monthly Charges
  * Customer Tenure
* Revenue analysis by city using bar chart and map visualization
* Revenue distribution by offers using donut chart
* Monthly charge comparison across offers using treemap
* Dynamic slicers for:

  * Internet Type (Cable, DSL, Fiber Optic)
  * Customer ID
* Customer-level revenue table for detailed insights
* Clean and modern UI with consistent green theme
* Fully interactive dashboard with cross-filtering

---

## 💼 Business Problem

Telecommunication companies deal with large volumes of customer data but often struggle to extract meaningful insights.

This project helps address:

* Identification of key revenue-generating cities
* Understanding which offers perform best
* Analyzing customer contribution to revenue
* Evaluating the impact of services like internet type on revenue

---

## ❓ Key Questions

* Which cities generate the highest revenue?
* Which offers contribute the most to total revenue?
* How are monthly charges distributed across different offers?
* What is the impact of internet type on customer revenue?
* Who are the top revenue-generating customers?
* How does customer tenure influence revenue and charges?

---

## 📌 Conclusion

The dashboard reveals that revenue is concentrated among specific cities and offers, with certain plans contributing significantly more to overall performance.

Key insights include:

* A few offers dominate total revenue contribution
* Certain cities act as major revenue hubs
* High-value customers drive a significant portion of revenue
* Internet type influences revenue variation

Overall, this dashboard provides an intuitive and interactive way to analyze telecommunication customer data, enabling better decision-making and strategic planning.
